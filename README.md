# AI Cloud DevOps Platform

A modern Cloud and DevOps project that demonstrates automated application deployment using Docker, CI/CD, Kubernetes, AWS and Infrastructure as Code.

## Project Goal

The goal of this project is to build a production-style DevOps platform where developers can push code to GitHub and the application can be automatically built, tested, containerized and deployed to cloud infrastructure.

## Current Status

- HTML application created
- Docker containerization completed
- Nginx configured as web server
- Git repository initialized
- GitHub repository connected
- Initial version pushed to GitHub
